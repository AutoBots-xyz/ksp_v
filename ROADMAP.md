# Roadmap

Future direction beyond the initial challenge delivery.

---

## Now — v1 Challenge Delivery

- Catalyst-hosted app with **role-based login**
- FIR data model (ER-aligned) + import
- SCRB / District / Station dashboards & maps
- Network & repeat offender views
- Trend spikes + risk scores (QuickML/Zia)
- Reports via SmartBrowz
- Pipelines CI/CD

---

## Next — v1.x Hardening (0–3 months post-demo)

| Item | Value |
|------|-------|
| Kannada UI i18n | Field usability |
| MFA rollout all command roles | Security |
| Refined entity resolution UI | Fewer false graph merges |
| Mobile-optimized IO case list | Field use |
| Advanced audit dashboards | Compliance |
| Threshold tuning per crime type | Fewer false alerts |
| Expanded master data (full Act/Section) | Legal fidelity |

---

## Later — v2 Intelligence Expansion (3–9 months)

| Item | Catalyst angle |
|------|----------------|
| CCTNS near-real-time connector | Connections + Circuits |
| Socio-economic live feeds | Scheduled ingest Stratus |
| RAG assistant on SCRB SOPs | QuickML RAG |
| Zia OCR for scanned FIR annexures | Zia Services |
| Cross-district task force workspaces | RBAC collaboration roles |
| Predictive resource allocation suggestions | AutoML + Circuits |
| Offline map packs for low connectivity | Client + Stratus |

---

## Future — v3 Ecosystem (9–18 months)

- NCRB / multi-state anonymized benchmark exchange (policy-dependent)
- Court outcome feedback loop into clearance analytics
- Voice briefings (Zia speech) for command summaries
- Dedicated data warehouse export for research cell
- Formal ISO-aligned ISMS documentation pack

---

## Explicitly Deferred

- Public citizen crime map with raw pins (privacy risk)
- Automated facial recognition dragnet (policy/ethics)
- Replacing full CCTNS transaction processing
- Unsupervised use of caste/religion in predictive models

---

## Dependency Assumptions

- Continued Catalyst service availability for Auth, Data Store, QuickML, Pipelines
- Department approval for data hosting & roles
- GeoJSON accuracy for Karnataka administrative boundaries
