# Seed Data

Master seed JSON files loaded by `scripts/seed-local.ts`.

- `districts.json` — Karnataka districts (StateID=29)
- `units_sample.json` — sample police stations per district
- `roles.json` — 8 RBAC role codes
- `crime_heads.json` — CrimeHead / CrimeSubHead classification
- `acts.json` / `sections.json` — Act & Section masters

Synthetic FIR generation handled by `scripts/generate-synthetic-data.ts` (sub-phase 1E).
